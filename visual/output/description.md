# Guided tour

The guided-tour component at version 0.5.0 provides ae/guided-tour version 1.0.0 to an illustrative application consumer, which in turn supplies ae/controls version 1.0.0 and ae/preferences version 1.0.0 and ae/language version 1.0.0. The 4 arrows each run from a named output to a required input of the same type and version. No configuration or secret values are displayed.
